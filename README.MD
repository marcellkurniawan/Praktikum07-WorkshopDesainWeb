# Dashboard Admin Sederhana | Bootstrap 5 UI Components

Sebuah proyek halaman web _Dashboard Admin_ interaktif dan responsif yang dikembangkan sebagai tugas praktikum **Modul 07: Bootstrap ke-02** pada mata kuliah **Workshop Desain Web**. Proyek ini mendemonstrasikan pengintegrasian berbagai komponen _user interface_ (UI) Bootstrap 5 modern seperti _Jumbotron/Header, Alerts, Buttons, Progress Bars,_ dan _Pagination_.

---

## 🚀 Fitur Utama & Kriteria Bootstrap

- **Header / Jumbotron:** Area penyambut administrator berbasis _Jumbotron_ kustom berwarna `#023269` dengan aksen `#f3c907` untuk memberikan gambaran umum sistem secara visual.
- **Notifikasi Alerts (3 Jenis):** Menyampaikan status feedback sistem secara interaktif menggunakan 3 jenis alert berbeda:
  1. _Success Alert_ (`.alert-success`) untuk konfirmasi pembaruan database.
  2. _Warning Alert_ (`.alert-warning`) untuk peringatan batas kapasitas memori.
  3. _Danger Alert_ (`.alert-danger`) dengan tombol penutup (_dismissible_) untuk pemberitahuan eror jaringan.
- **Panel Kontrol Buttons:** Menyediakan kontrol aksi cepat admin menggunakan variasi warna kontekstual, ukuran tombol (`.btn-sm`, `.btn-lg`), gaya _outline_, serta tombol terkelompok (`.btn-group`).
- **Progress Bars Statistik:** Visualisasi indikator kinerja server (_Storage, CPU Load,_ dan _Target Mahasiswa Baru_) menggunakan gaya bergaris (`.progress-bar-striped`) dan beranimasi (`.progress-bar-animated`).
- **Pagination Data Log:** Navigasi penomoran halaman data log aktivitas sistem menggunakan komponen `.pagination` yang rapi dan interaktif.
- **Identitas Warna Kustom:** Mengintegrasikan skema warna identitas kampus khusus, yaitu `#023269` (Biru Utama) dan `#f3c907` (Kuning Emas) pada komponen Bootstrap.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5** (Struktur Dokumen Semantik)
- **CSS3** (Variabel Kustom & Styling Warna Kampus)
- **Bootstrap 5** (Jumbotron, Alerts, Buttons, Progress Bars, Pagination, Components CDN)
- **JavaScript ES6 / Bootstrap Bundle** (Interaktivitas Alert Dismissible & Components)

---

## 📂 Section Halaman yang Disediakan

1. **Header Dashboard (Jumbotron):** Salam pembuka admin, ringkasan sistem, dan tombol aksi utama.
2. **Status & Notifikasi Sistem (Alerts):** Papan informasi pembaruan, peringatan kapasitas, dan eror server.
3. **Statistik Kinerja Server (Progress Bars):** Indikator visual real-time untuk penyimpanan, beban CPU, dan kuota pendaftaran.
4. **Panel Kontrol Quick Action (Buttons):** Tombol eksekusi aksi admin dan filter mode data.
5. **Log Aktivitas Sistem (Table & Pagination):** Tabel riwayat aktivitas pengguna yang dilengkapi navigasi halaman data.
